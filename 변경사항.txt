                             CentOS 7/8 미지원 안내 추가

 2. OpenSSL 자체 서명 도입
================================================================================

 [결정] 공인 CA 인증서 대신 OpenSSL 자체 서명 사용 (비용 무료)
        Windows SmartScreen 경고는 수용

 신규 파일
  - scripts/sign-release.js   자체 서명 파이프라인 (신규)

 npm 스크립트
  - npm run sign          인증서 준비 + 전 배포 파일 서명 + 자가 검증
  - npm run sign:cert     인증서만 생성 (electron-builder 연동용)
  - npm run dist:secure   난독화 → 패키징 → 서명 → 해시 (일괄)

 동작
  1) signing/ 에 인증서가 없으면 생성
       RSA 3072 / SHA-256 / keyUsage=digitalSignature
       extendedKeyUsage=codeSigning / 유효기간 10년
       Subject: C=KR, O=Yeoulgame, OU=Yeoulgame Research Team,
                CN=Yeoulgame SSH Client
  2) release/ 의 모든 배포 파일에 detached 서명(.sig) 생성
       생성 직후 공개키로 자가 검증 → 실패 시 빌드 중단
  3) Windows 에서 signtool 이 있으면 .exe 에 Authenticode 적용
       없으면 건너뜀 (.sig 와 해시로 무결성 검증은 그대로 가능)
  4) release/yeoulgame-public-cert.crt 배포용 공개 인증서 복사
  5) release/SIGNATURE.md 자동 생성
       공개 인증서 지문(SHA-256), 인증서 만료일,
       파일별 SHA-256 표, 사용자용 검증 명령어, 경고 화면 대처법

 빌드 스크립트 연동
  - scripts/build-win.ps1    기본 서명 포함. -NoSign 으로 생략 가능
                             CSC_LINK / CSC_KEY_PASSWORD 자동 설정
  - scripts/build-linux.sh   기본 서명 포함. --no-sign 으로 생략 가능
                             GPG_KEY_ID 지정 시 GPG 추가 서명

 문서 반영
  - INSTALL.md 1장   "먼저 읽어주세요 - 이 프로그램은 자체 서명되어 있습니다"
  - INSTALL.md 3장   파일 검증 (해시·서명) 신규 장 추가, 이후 장 번호 조정
  - INSTALL.md 6장   SmartScreen / 게시자 경고 항목 추가
  - BUILD.md 6장     서명 절차를 자체 서명 기준으로 전면 교체, 인증서 관리 수칙
  - README.md        "배포판은 자체 서명입니다" 절 추가
  - SECURITY_REPORT.md 3장  서명 항목 갱신 + "자체 서명의 보증 범위" 표 추가

 개발 환경 검증 결과
  - 인증서 생성            OK
  - 3개 파일 서명 + 검증    OK (Verified OK)
  - 변조 파일 거부          OK (1바이트 추가 시 Verification failure)
  - 인증서 속성 확인        OK (Code Signing EKU, Digital Signature)
  - 문서에 적힌 검증 명령   실제 실행하여 동작 확인 완료

 ※ 연구팀 확인 요청 2건

  (1) 자체 서명은 SmartScreen 경고를 없애지 못합니다.
      오히려 "알 수 없는 게시자" → "신뢰할 수 없는 인증서" 로 문구가 바뀔 수
      있습니다. 결정문에서 수용하신 내용이라 그대로 진행했습니다.

  (2) 자체 서명의 실효는 사용자가 공개 인증서 지문을 공식 배포처와 대조할 때만
      생깁니다. 아래 두 곳에 지문을 반드시 게시해 주세요.
        - https://yeoulgame.com/downloads
        - GitHub Release 본문
      게시하지 않으면 서명 작업이 무의미해집니다.

 ※ 개인키 관리
  signing/ 폴더는 .gitignore 에 등록했습니다.
   - 유출 시 : 제3자가 여울게임터 이름으로 서명 가능
   - 분실 시 : 기존 사용자가 새 배포판의 서명을 검증할 수 없음
  오프라인 백업을 권장합니다.
